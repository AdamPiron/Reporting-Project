# Reporting-Project

Monthly debt-investor reporting webpages for **Electra Belgium**, published with GitHub Pages, together with the Claude skills that generate them.

> **Demo data.** Every report is an illustrative template using randomized figures, for demonstration purposes only. Nothing here reflects Electra's actual performance.

Each report is a single self-contained HTML file (inline CSS and JavaScript, no build step). One file is added per month, named `electra-reporting-belgium-<Month>-<Year>.html`.

## How a report is produced

The reports are generated by a chain of Claude skills, kept in [`skills/`](skills/). Each step feeds the next:

| # | Skill | What it does |
| --- | --- | --- |
| 0 | [`electra-monthly-pipeline`](skills/00-electra-monthly-pipeline.md) | Runs steps 1–4 and 6 in sequence, pausing after step 3 for review of the content. |
| 1 | [`electra-monthly-data`](skills/01-electra-monthly-data.md) | Rolls the raw-data file forward one month, keeping figures coherent (stations, energy, revenue, EBITDA, debt drawn, covenants, YTD totals). |
| 2 | [`electra-notion-ops-report`](skills/02-electra-notion-ops-report.md) | Creates the month's "Operations Report" page in Notion, with figures taken 1:1 from the raw data. |
| 3 | [`electra-webpage-content`](skills/03-electra-webpage-content.md) | Writes the webpage content as Markdown: figures from the raw data, commentary from the Notion report. |
| 4 | [`update-electra-report`](skills/04-update-electra-report.md) | Renders the approved Markdown into the next HTML report, reusing the previous month's design. |
| 5 | [`send-electra-report`](skills/05-send-electra-report.md) | Renders the latest report to PDF and emails it to the recipient list. |
| 6 | [`publish-electra-to-github`](skills/06-publish-electra-to-github.md) | Pushes the latest HTML report to this repo, where GitHub Pages serves it. |

The raw data, Notion pages and Markdown content live outside this repo; only the finished HTML reports and the skill definitions are stored here.

## Repository layout

```
.
├── electra-reporting-belgium-<Month>-<Year>.html   # one report per month
└── skills/                                         # Claude skills that build and publish the reports
```

## Viewing a report locally

Clone the repo and open any `.html` file in a browser. No server or dependencies are needed.

## Publishing

GitHub Pages serves the `main` branch from the repository root, so a report is live at `https://adampiron.github.io/Reporting-Project/<filename>` shortly after it is pushed. When adding a month, add a row to the Reports table above.
